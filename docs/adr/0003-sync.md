# ADR 0003: Local authority, explicit outbox, HLC records and Yjs bodies

2026-10-10. Dexie IndexedDB on all clients, HLC per-field scalar last-writer-wins,
and one Yjs document per page. Alternatives: backend authority, PowerSync/Electric,
SQLite WASM/OPFS. IndexedDB supports the same UI/store in Safari and WebView2.

Evidence: 500 generated merge cases check associativity, commutativity and
idempotence. Clock tests cover rollback, remote observations and invalid input.
Three disconnected Yjs documents retain multilingual edits after reordered and
duplicate delivery. The browser study binds real editor changes to Yjs and
transactionally merges snapshots; BroadcastChannel connects same-device tabs.

Go for Phase 1 engine work. This is not authenticated cloud outbox/pull/realtime.
Implement idempotent operations, cursors, backoff, tombstones, schema migration,
owner policies and three application-client convergence tests. Test delayed
delivery after deletion and far-future clocks. Fallback: replace transport while
preserving local adapters, unsynced work and portable exports.
